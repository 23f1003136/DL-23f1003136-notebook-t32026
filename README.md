# SurfaceGuard AI: Industrial Surface Anomaly Segmentation

## Project Overview
This project aims to detect, classify, and segment surface defects in industrial images using computer vision and deep learning.

## Objectives
- Detect anomalies in industrial surface images.
- Classify defects into four categories.
- Identify defect locations using pixel-level segmentation masks.
- Evaluate predictions using the competition's scoring metric.

## Dataset
Dataset provided by the Kaggle competition: SurfaceGuard AI — Industrial Surface Anomaly Segmentation.
